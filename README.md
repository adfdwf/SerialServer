# SerialServer

`SerialServer` 是与 `SerialEvaluation` 客户端配套的多端口 TCP 性能测试服务端。它可以在同一个 IP 地址上同时监听多个端口，并实时显示每个端口及全部端口的连接与吞吐统计。

## 功能

- 同一 IP 同时监听多个端口，支持列表和范围语法，例如 `1-65534`。
- 每个端口使用独立工作线程，网络收发不占用界面线程，不同端口之间互不阻塞。
- 每个客户端连接维护独立接收缓冲区，支持 TCP 拆包和粘包。
- 识别客户端使用的 `A0 81` 协议帧，并返回设备格式 `A0 00 64 81 ... 10 checksum` 的 9 字节响应。
- 非协议 ASCII/HEX 原始数据按接收块原样 Echo。
- 显示每端口的活动连接、累计连接、请求/响应数、收发字节、实时 MiB/s 和协议错误。
- 写队列超过 64 MiB 时主动断开慢连接，避免单个客户端耗尽服务端内存。

## 协议兼容性

对于 `A0 81` 帧，服务端与客户端采用相同帧格式：

| 字节 | 含义 |
|---|---|
| 0..1 | 帧头 `A0 81` |
| 2 | 命令字 |
| 3..6 | Payload 长度，大端序 |
| 7 | 头字段 |
| 8..N | Payload |
| 最后 1 字节 | 前面所有字节累加和的低 8 位 |

对于任意合法长度（当前安全上限 4 MiB）的 `A0 81` 请求，服务端会先按长度字段接收完整帧、验证校验和，再返回设备格式的固定状态响应；响应不会回传请求 payload。非协议数据仍按接收块原样返回。客户端当前按照发送顺序匹配响应，因此同一连接上的响应顺序不能改变；本服务端保证这一点。

例如请求：

```text
A0 81 01 00 00 00 00 00 22
```

返回：

```text
A0 00 64 81 01 00 00 10 96
```

## 构建

依赖 Qt 5.15+ 或 Qt 6，组件为 Core、Widgets、Network。

```powershell
cmake -S . -B out/build -G "Visual Studio 17 2022" -A x64 `
  -DCMAKE_PREFIX_PATH=D:/Soft/QT/Qt/6.8.3/msvc2022_64 `
  -DBUILD_TESTING=ON
cmake --build out/build --config Release --parallel
ctest --test-dir out/build -C Release --output-on-failure
```

程序位于 `out/build/Release/SerialServer.exe`。

## 使用

1. 在 `Listen IP` 选择服务端网卡地址。仅本机测试可选择 `127.0.0.1`；允许其他计算机访问可选择实际网卡 IP 或 `0.0.0.0`。
2. 在 `Ports` 输入端口，例如 `1-65534`，单次最多启动 128 个端口。
3. 点击 `Start Servers`。
4. 在一个或多个 `SerialEvaluation` 客户端中填写服务端 IP 和不同端口，连接后点击 `Start`。
5. 对比客户端延迟/成功率与服务端连接数、吞吐率和错误数。

Windows 首次监听时可能出现防火墙提示。跨机器测试需要允许该程序通过对应网络类型的防火墙。

## 性能测试建议

- 客户端和服务端在同一台机器时，结果主要反映软件栈与 CPU 性能；测试网络性能应部署在两台机器上。
- 测试服务端多端口性能时，需要启动多个客户端实例并分别连接不同端口。
- 客户端发送 ASCII 原始数据时，TCP 本身没有消息边界；极高频率下多个发送可能合并为一个接收块。推荐性能测试使用带长度字段和校验和的 `A0 81` 协议帧。
- 客户端界面日志渲染也会影响高频测试结果，测试时应同时观察服务端统计。
